Usá afinación estándar: Mi, La, Re, Sol, Si, Mi (de grave a aguda), sin cejilla. Tocá una cuerda por marca y apagá la anterior. Para aprobar deben coincidir nota y ataque; sostener una nota no cuenta como nuevos ataques.

Usá auriculares para el metrónomo. La demostración reproduce una referencia sintetizada y no suma puntos. El análisis se hace en tu navegador: no guardamos ni enviamos tu audio. Esta primera versión funciona con notas individuales; el ruido y varias cuerdas sonando pueden confundirla.

Si tocás a tiempo pero siempre aparece “tarde”, aumentá esta compensación. Si aparece “antes”, reducíla. La exigencia se puede bajar para empezar.
